# Frontend Setup (Vite + React)

## Prerequisites
- Node.js and npm (or yarn) installed.

## Getting Started

1.  Navigate to the `frontend` directory.
2.  Install project dependencies:
    ```bash
    npm install
    ```
    (This step might already be partially or fully covered if `npm create vite@latest` also installs dependencies, but it's good practice to include it.)

## Running the Development Server

1.  Navigate to the `frontend` directory.
2.  Start the Vite development server:
    ```bash
    npm run dev
    ```
The application will typically start on `http://localhost:5173` or the next available port.
